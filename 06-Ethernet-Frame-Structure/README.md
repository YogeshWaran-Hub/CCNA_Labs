# 06-Ethernet-Frame-Structure

## 📘 Overview

An **Ethernet Frame** is the standard data unit used for communication in Ethernet networks. It encapsulates data with addressing, protocol information, and error-checking fields before transmission over a Local Area Network (LAN). Defined by the **IEEE 802.3** standard, the Ethernet frame enables reliable communication between network devices by using **MAC addresses** for addressing and **CRC-32** for error detection.

---

## 📚 Ethernet Frame Format

```text
+-----------+-----+-------------+-------------+-----------+----------------+------+
| Preamble  | SFD | Destination |   Source    | Type/Len  |    Payload     | FCS  |
| 7 Bytes   |1 B  | MAC (6 B)   | MAC (6 B)   | 2 Bytes   | 46–1500 Bytes  |4 B   |
+-----------+-----+-------------+-------------+-----------+----------------+------+
```

---

## 📋 Ethernet Frame Fields

| Field | Size | Description |
|-------|:----:|-------------|
| **Preamble** | 7 Bytes | Synchronizes communication between sender and receiver. |
| **Start Frame Delimiter (SFD)** | 1 Byte | Indicates the beginning of the Ethernet frame. |
| **Destination MAC Address** | 6 Bytes | Identifies the intended receiving device. |
| **Source MAC Address** | 6 Bytes | Identifies the transmitting device. |
| **EtherType / Length** | 2 Bytes | Indicates the encapsulated protocol or payload length. |
| **Payload (Data)** | 46–1500 Bytes | Contains the user data being transmitted. |
| **Frame Check Sequence (FCS)** | 4 Bytes | Detects transmission errors using CRC-32. |

---

## 🔄 Ethernet Frame Transmission

1. Data is generated by the application.
2. The Data Link Layer encapsulates the data into an Ethernet frame.
3. Source and destination MAC addresses are added.
4. The frame is transmitted through the physical medium.
5. Switches forward the frame based on the destination MAC address.
6. The receiver validates the Frame Check Sequence (FCS).
7. If no errors are detected, the payload is delivered to the Network Layer.

---

## 📏 Frame Size

| Property | Value |
|----------|:-----:|
| Minimum Frame Size | **64 Bytes** |
| Maximum Standard Frame Size | **1518 Bytes** |
| Maximum Payload | **1500 Bytes** |
| Header | **14 Bytes** |
| FCS | **4 Bytes** |

> **Note:** If the payload is smaller than **46 bytes**, padding is added to meet the minimum frame size requirement.

| VLAN (802.1Q) | `0x8100` |

---

## 💡 Key Notes

- Ethernet operates at the **Data Link Layer (Layer 2)** of the OSI model.
- Every network interface has a unique **48-bit MAC Address**.
- Ethernet II is the most commonly used frame format today.
- The **Maximum Transmission Unit (MTU)** is **1500 bytes**.
- Frames smaller than **64 bytes** are padded automatically.
- The **Frame Check Sequence (FCS)** uses **CRC-32** for error detection.
- Ethernet switches forward frames using the **Destination MAC Address**.
